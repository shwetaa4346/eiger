# Eiger AI Security Assessment

## Overview

This repository contains my hands-on AI Security Assessment performed in the authorized Eiger AI Security Lab training environment.

The assessment covers M1-M8 and the Capstone, focusing on practical AI security concepts including prompt injection, output handling and stored XSS, RAG poisoning, AI/ML supply-chain security, excessive agency, MCP tool poisoning, multi-agent trust, guardrail bypass, and an end-to-end AI security attack chain.
